### 🐘 PostgreSQL tools I've built

| Project | What it does | Stack |
|---|---|---|
| [**pg_ext_memcheck**](https://github.com/samsiva-dev/pg_ext_memcheck) | Extension that diagnoses memory bugs in *other* extensions — MemoryContext leaks, wrong-context allocations and shmem overruns, caught from inside the running backend. | C · PG Extension |
| [**pg_mcp_server**](https://github.com/samsiva-dev/pg_mcp_server) | Local, offline PostgreSQL internals assistant — semantic search over the PG source, exposed as MCP tools in Zed and VS Code. Zero API cost. | Python · pgvector · Ollama · MCP |
| [**pg-log-parser**](https://github.com/samsiva-dev/pg-log-parser) | Parses PostgreSQL server logs, normalizes query fingerprints, and ranks the slowest queries and most frequent errors. | Rust · CLI |
| [**pg_join_optimizer**](https://github.com/samsiva-dev/pg_join_optimizer) | Statistics-driven join-order optimizer CLI for PostgreSQL. | Go · CLI |
| [**PG Radar**](https://github.com/samsiva-dev/PG-Radar) · [live](https://pg-radar-beta.vercel.app/) | One dashboard for the PostgreSQL community: pgsql-hackers & pgsql-committers threads, recent commits, CommitFest patches and Planet PostgreSQL. | Next.js · React |
| [**db_backup_utility**](https://github.com/samsiva-dev/db_backup_utility) | CLI to back up and restore databases and automate backup jobs. | Go · Cobra |
